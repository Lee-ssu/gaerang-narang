# 개랑 나랑

반려견에게 맞는 여행지를 차량에서 찾아 기본 내비로 안내하고, 이동 중 돌봄과 방문 기록까지 이어 주는 Pleos Connect 앱입니다.

현대자동차그룹 차량용 앱 개발 공모전 · 팀 **똥강아지들**

## APK 설치 및 실행

[서명된 제출용 APK](apk/똥강아지들_개랑나랑_release.apk)를 내려받습니다. Pleos Connect 에뮬레이터를 실행한 상태에서 저장소 루트의 터미널에서 다음 명령을 실행합니다.

```sh
adb install 'apk/똥강아지들_개랑나랑_release.apk'
adb shell am start -n kr.gaerang/.MainActivity
```

같은 패키지의 디버그 APK가 이미 설치된 에뮬레이터에서는 새 AVD를 사용합니다. 디버그 APK와 제출용 APK는 서명이 달라 같은 설치 위에서 업데이트할 수 없습니다.

## 테스트 환경 및 설정

| 항목 | 환경 |
| --- | --- |
| 차량 에뮬레이터 | Pleos Connect Emulator 2.1.0 · Android 14(API 34) · ARM64 |
| 에뮬레이터 디스플레이 | 2560×1440 px |
| 앱 디자인 기준 | 가로 1280×906 · 좁은 분할 창 640×906 |
| 시스템 앱 | Pleos 기본 내비게이션 |
| 소스 빌드 | JDK 17 · Android SDK Platform 35 · Gradle Wrapper 8.10.2 |

앱 설치와 조작은 P단에서 시작합니다. 차량 신호와 제어를 확인하려면 Pleos 가상 콘솔을 연결하고, 휴식 알림을 확인하려면 앱의 차량 알림을 허용합니다. 분할 화면에서는 에뮬레이터의 전체 해상도 안에서 앱이 할당받은 창 크기에 맞춰 배치됩니다. [플레오스 가상 콘솔 가이드](https://document.pleos.ai/docs/pleos-only/app-test-guide/virtual-console-guide)

## 심사 시연

제출용 릴리스는 공모전 시연 옵션을 포함합니다. 저장된 프로필이 없으면 예시 반려견 **초코**가 표시됩니다. **초코** 탭에서 실제 반려견 프로필을 등록할 수 있습니다.

1. **산책길**에서 초코와 갈 곳을 고릅니다. 실내 동반 여부와 체중·견종 등 등록 프로필의 조건을 적용합니다. 넓은 운동장이나 정원, 바닷가, 반려견과 걸을 수 있는 충전소를 둘러보고 실제 장소를 코스에 추가합니다. 목적지가 있는 상태에서 충전소를 추가하면 충전소가 먼저 들를 경유지가 됩니다.
2. **내비로 안내**를 누르면 기본 내비게이션으로 경로를 요청합니다. **내비 동행 미리보기 → 분할 화면에서 D단 시연**을 눌러 기본 내비가 열리면, 오른쪽 끝의 `⋮` 막대를 왼쪽으로 끕니다. 실제 기어를 P단에 둔 채 **P단 · D단 시연** 표시, 달리는 초코, 선택한 목적지를 기본 내비 옆에서 볼 수 있습니다.
3. **우리 집**에서 온도·시트·창문·문 항목을 선택하면 현재 화면의 조작 팝업이 열립니다. 공조 자동 조정은 앱을 처음 설치하면 꺼져 있습니다. 홈에서 켜면 등록한 자리의 탑승 신호를 바탕으로 차량이 지원하는 공조 설정값을 적용합니다.
4. **안심**에서 보호자 영상을 재생하거나 별도의 음성 파일을 지정할 수 있습니다. 영상은 앱에 포함되어 있어 파일을 내려받을 필요가 없습니다. **D단 화면 미리보기**에서는 낮·밤 주행과 휴식 안내, 휴게소, 창문 올림 화면을 살펴볼 수 있습니다.
5. **발자국**에서 다녀온 장소, 한마디, 사진을 저장합니다. 위치가 있는 장소는 발자국 지도에 표시됩니다. 음성 입력에는 차량에 설치된 Android 음성 인식 앱이 필요합니다.

내비와 함께 쓰는 표시 전용 Activity에 Distraction Optimized(DO)를 선언했습니다. 실제 D단에서는 Pleos의 주행 중 사용 제한에 따라 시스템 제한 화면이 표시될 수 있습니다.

동승을 시작하면 차량 주행 신호에 따라 시간이 누적됩니다. 릴리스의 알림은 실제 주행 시간 기준으로 90분에 쉼터 계획, 110분과 115분에 휴식 임박, 120분에 휴식 권장을 보여 줍니다. P단에서 **휴식 시작**을 누르면 **휴식 마쳤어요**가 나타납니다. 휴식을 마친 뒤 출발하면 시간을 다시 셉니다. 기본 내비가 쉼터 경유지를 확인한 경우에는 휴식 임박 알림을 생략합니다.

## 연동 기능

- **장소 추천과 충전·산책.** 울산 시범 지역의 실제 장소와 동반 조건 시연 데이터를 제공합니다. 충전·산책은 애니언파크, 태화강 국가정원, 간절곶공원 인근의 등록 충전소와 산책 공간을 소개합니다. 장소 상세에서 시설 안내와 충전소 조회를 열 수 있습니다. 장소 순서는 현재 위치와 목적지 좌표를 바탕으로 계산하며 도로 소요 시간과 실시간 충전기 상태는 제공처에서 확인합니다.
- **차량 상태와 조작.** AAOS 기어와 주행 제한 신호로 조작 가능 여부를 판단합니다. Vehicle SDK로 등록 좌석의 도어·창문·착석·온도 등을 읽고, 지원되는 구역에서 공조·창문·문·시트 통풍을 조작합니다. 실내 실측 온도가 없을 때는 확인 가능한 에어컨 설정 온도와 적용 구역을 표시합니다. [Vehicle SDK](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/Vehicle/intro)
- **창문 프리셋과 알림.** 기본 프리셋은 10%, 30%, 50%이며, **프리셋 설정**에서 차량이 지원하는 위치를 저장할 수 있습니다. 창문 올림 안내에서는 약 10%를 목표로 3초 뒤 요청하고, **지금 올리기**로 즉시 실행하거나 **그대로 두기**로 취소합니다.
- **내비게이션.** NaviHelper SDK로 현재 위치와 내비 목적지를 확인하고 실제 목적지·경유지를 요청합니다. 내비에서 전달받은 도착 정보와 경로 상태를 앱에 표시합니다. [NaviHelper 경유지 설정](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/NaviHelper/route-with-waypoints)
- **같은 곳으로 가는 반려견.** 서버가 없는 제출용 시연에서는 애니언파크·태화강 국가정원·간절곶의 예시 동행 수를 `시연`으로 표시합니다. 실시간 집계 서버가 연결된 빌드에서는 사용자가 공유를 켜고 내비 안내가 확인된 장소에서만 장소 ID와 임시 세션 ID, 반려견 수로 집계합니다. 세션은 종료되거나 45초 동안 갱신이 없으면 집계에서 빠집니다.
- **반려견 프로필과 화면 디자인.** 반려견 이름·견종·나이·체중·좌석·탑승 형태와 교류 성향을 설정할 수 있습니다. 캐리커처 색상과 낮·밤 모드를 지원합니다. 화면은 팀이 제작한 가로·세로 ZIP 디자인을 앱과 연동했습니다.
- **글레오.** App Schema와 Android 액션 수신을 구현했습니다. 실제 음성 호출은 글레오가 제공되는 환경에서 확인할 수 있습니다. [Gleo Interface](https://document.pleos.ai/docs/pleos-only/app-integration-guide/guide/core-concepts)

## 소스 빌드

Android Studio에서 저장소를 열거나 프로젝트 루트에서 다음 명령을 실행합니다. 첫 빌드는 공식 Pleos Maven, Google Maven, Maven Central에서 의존성을 내려받습니다.

```sh
./gradlew :app:assembleRelease -PgaerangShowcase=true
```

로컬에서 새로 만든 릴리스를 설치하려면 본인의 서명 키로 서명합니다. 제출용 서명 APK는 [apk 폴더](apk/)에 있습니다. 함께 가는 반려견의 실시간 집계를 연동하려면 공통 HTTPS 서버를 준비한 뒤 빌드에 `-PgaerangPresenceUrl=https://<host>`를 전달합니다.

개발 중 로컬 집계 서버를 쓸 때는 디버그 빌드와 아래 명령을 사용합니다.

```sh
python3 tools/outing_presence.py
# 별도 터미널에서
adb reverse tcp:8765 tcp:8765
```
